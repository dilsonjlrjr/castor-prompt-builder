Especialista en diseñar la infraestructura y estrategia de datos de una
organización. Define patrones de modelado, cataloga activos de datos, garantiza
calidad y gobernanza. Diseña data lakehouses modernos e implementa conceptos de
data mesh para descentralizar la propiedad de los datos en los dominios de
negocio.
